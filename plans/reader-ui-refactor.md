# 阅读器 UI 重构方案

## 目标

参照截图中的阅读器 UI 设计，重构当前阅读页面和朗读页面。

---

## 当前结构 vs 目标结构

### 当前结构
- `Reader.ets` — 主阅读页面（包含 ReaderKit 组件、目录/设置面板、TTS 页面）
- `ReadMenus.ets` — 独立菜单组件（未被 Reader.ets 使用，是死代码）
- 底部菜单：目录列表 / 设置 两个 Tab
- TTS 页面：全屏覆盖，有封面、控制按钮

### 目标结构（参照截图）
- 阅读页面：全屏文本 + 顶部章节标题 + 朗读高亮
- 底部导航栏：4 个 Tab（目录 | 字体 | 亮度 | 翻页）
- 朗读控制：浮动小控制条（不是全屏页面）
- 各 Tab 对应的底部弹出面板
- 右上角：更多菜单（阅读设置、添加书签、背景音乐、全文搜索）

---

## 重构步骤

### 第 1 步：重构底部导航栏（Reader.ets）

替换当前的「目录列表 / 设置」两个 Tab 为 4 个图标 Tab：

```
┌──────────┬──────────┬──────────┬──────────┐
│  ≡ 目录  │  A 字体  │  ☀ 亮度  │  📖 翻页 │
└──────────┴──────────┴──────────┴──────────┘
```

每个 Tab 点击后弹出对应的面板（使用 bindSheet）。

涉及文件：`Reader.ets`

### 第 2 步：重构目录面板

目标样式：
- 顶部：书籍封面缩略图 + 书名
- Tab 切换：目录 / 笔记
- 章节总数 + 筛选按钮
- 章节列表（当前章节高亮为绿色）
- 面板高度约 80%

涉及文件：`Reader.ets`（buildCatalogItemList 方法）

### 第 3 步：新增字体设置面板

目标样式：
- 字号调节：A 小 ← 滑块 → A 大
- 行距调节：≡ 紧 ← 滑块 → ≡ 松
- 字体选择：系统字体 >
- 对齐方式：自动对齐 ▼

涉及文件：`Reader.ets`（新增 buildFontPanel 方法）

### 第 4 步：新增亮度/主题面板

目标样式：
- 横向滚动的主题色圆形选择器（白天、夜晚、白色、黄色、粉色、绿色等）
- 当前选中主题有边框高亮

涉及文件：`Reader.ets`（新增 buildThemePanel 方法）

### 第 5 步：新增翻页设置面板

目标样式：
- 翻页方式：仿真 ▼
- 单手模式：开关
- 开启自动翻页按钮

涉及文件：`Reader.ets`（新增 buildPageFlipPanel 方法）

### 第 6 步：重构顶部栏

目标样式：
- 左上角：返回按钮 <
- 右上角：朗读按钮（耳机图标）+ 更多按钮（三点菜单）
- 更多菜单弹出：阅读设置、添加书签、背景音乐、全文搜索

涉及文件：`Reader.ets`

### 第 7 步：重构朗读控制为浮动条

替换当前的全屏 TTS 页面为底部浮动控制条：

```
┌─────────────────────────────────────────┐
│  📕  ⏸  ✕                    🔊 听     │
└─────────────────────────────────────────┘
```

- 左侧：书籍小图标 + 暂停按钮 + 关闭按钮
- 右侧：「听」按钮（带音波图标）
- 朗读时文本内联高亮（绿色背景），不需要单独的朗读页面

涉及文件：`Reader.ets`（修改 buildTTSPage → buildTTSFloatingBar）

### 第 8 步：实现朗读文本内联高亮

在阅读页面的正文中，当前朗读到的句子/短语显示绿色背景高亮，随朗读进度自动移动。

注意：这需要 ReaderKit 的 ReadPageComponent 支持自定义渲染。如果 ReaderKit 不支持内联高亮，则保留当前的独立高亮文本区域方案。

涉及文件：`Reader.ets`

### 第 9 步：底部进度条

在底部导航栏上方添加章节进度条：

```
  <  ○────────────────────  >
```

- 左箭头：上一章
- 右箭头：下一章
- 圆形滑块：当前页进度

涉及文件：`Reader.ets`

## 文件变更范围

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `Reader.ets` | 大幅修改 | 主要改动文件，重构 build() 方法和所有面板 |
| `ReadMenus.ets` | 可选删除 | 当前未被使用，可以保留或删除 |
| 新增资源文件 | 可能需要 | 主题色圆形图片等 |

---

## 注意事项

1. ReaderKit 的 ReadPageComponent 是华为提供的阅读渲染组件，我们无法修改其内部渲染逻辑，因此朗读内联高亮可能需要通过覆盖层实现
2. 当前 Reader.ets 已有 2300+ 行代码，重构时应考虑将面板组件拆分为独立文件
3. 保持现有的 TTS 功能逻辑不变，只修改 UI 展示层
